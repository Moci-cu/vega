# Unit-4 wallpaper picker assets

The picker UI and wave videos are adapted from Unit-4 by samyns, under the
MIT license included here. The MP4 files were generated by Unit-4's
`quickshell/pixel_video.cpp`; no generator is needed at runtime.

Vega uses Qt's folder model to list images and `Wallpapers.apply()` to apply
the selected image and update the theme. Its existing wallpaper setting is
global, so Apply targets all screens. Cancel and Escape leave it unchanged.

Open with Ctrl+Super+T or `qs -c ii ipc call wallpaperSelector toggle`.
Navigate with arrows, H/L, the wheel, or adjacent thumbnails; Enter applies.
